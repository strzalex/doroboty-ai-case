# Week 3 real-person prototype test

## Consent script

“Testujemy prototyp procesu aplikowania, nie Ciebie ani Twoje kompetencje. Dane są syntetyczne. Sesja potrwa około 25 minut. Nie wpisuj prawdziwego nazwiska, telefonu, adresu e-mail używanego prywatnie ani poufnych informacji o pracy. Możesz przerwać w dowolnym momencie. Czy zgadzasz się kontynuować?”

Record only `yes/no`, the synthetic participant code, date, tested release, and facilitator.

## Scenario

1. Find a role that seems relevant.
2. Explain what the employer appears to value.
3. Prepare and submit an application using only the supplied synthetic profile.
4. If an AI draft is available, decide whether to use it, edit it, or discard it.
5. Show what you believe the employer will learn from the final answer.

Do not teach the interface. Ask “Co teraz próbujesz zrobić?” and “Czego się spodziewasz?” when the participant pauses.

## Observation notes

Capture timestamps and observable behavior, not interpretations:

| Moment | What happened | Quote or action | Severity            | Follow-up question |
| ------ | ------------- | --------------- | ------------------- | ------------------ |
|        |               |                 | low / medium / high |                    |

After the task, ask what evidence the participant intentionally kept, removed, or could not express. Keep product learning separate from recruiting judgments.

## Learning record

Write one `docs/learnings/YYYY-MM-DD-short-name.md` containing hypothesis, participant code, release, evidence, surprise, limitation, decision, and next test. Do not include names, contact details, raw private URLs, or copied employer/candidate free text.
