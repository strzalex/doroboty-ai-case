argument-hint: [task-name or brief]
---

Create a durable plan for: $ARGUMENTS

Use the project context and write the result to `docs/tasks/` or `docs/prds/`.

The plan must include:

- Goal
- Non-goals
- Assumptions
- Relevant files/modules
- Implementation steps
- Acceptance criteria
- Verification commands
- Risks and review focus

Do not implement unless explicitly asked.
